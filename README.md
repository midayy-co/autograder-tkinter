# Autograder Tugas Tkinter: Konverter Suhu

Autograder mini project Tkinter (Praktikum Pemrograman Komputer 2).

- **Cek mandiri (praktikan):** tempel `main.py`, klik Nilai, nilai dan rinciannya langsung keluar.
- **Rekap nilai (asisten):** masukkan semua zip `[NPM]_[Nama]_Tkinter.zip`, lalu unduh CSV.

Program praktikan dijalankan di browser dengan [Pyodide](https://pyodide.org) 0.26.4 dan Tkinter tiruan
(`faketk.py`): Entry diisi, Radiobutton dipilih, dan Button diklik otomatis. Kode praktikan tidak dikirim ke server mana pun.

`grader.py` juga bisa dijalankan langsung: `python grader.py main.py`
